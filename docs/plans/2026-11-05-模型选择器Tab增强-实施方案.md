# 模型选择器 Tab 增强 —— 实施方案

> 前置勘察见 [技术勘察](2026-11-05-模型选择器Tab增强-技术勘察.md)。本文是定稿的实施契约。

## 一、已确认的决策

| # | 决策项 | 结论 |
|---|---|---|
| 1 | 实现路径 | **A+ 整体替换 `conversation.input.model` 槽，自实现 effort 档位列表** |
| 2 | Tab 形态 | **模型列表页内两级 Tab**：Provider 横排（一级）+ 族横排（二级），均保留「全部」 |
| 3 | 族识别 | **厂商词表最长前缀优先 + 回退「前导字母串」**，规则可配置 |
| 4 | 与 reasoning-effort | **我们接管整个槽**；对方的滑块 UI 不再上屏（不会报错），其 effort 功能由我们吸收 |
| 5 | 差异化 | **以「族规则可配置 + 稳定 ID」为主卖点**，Tab 作为大目录形态 |
| 6 | 生效范围 | **仅大目录切 Tab**（总模型 > 20 或 单 provider > 30），否则退回官方平铺样式 |

## 二、不可达项（明确声明，不做）

| 项 | 原因 |
|---|---|
| `/model` 斜杠命令的 Tab 化 | 走 `commandUi.popupSelect`，由 `ui-commands` 自渲染，插件无注入点 |
| 保留 `conversation.input.model.label` 子槽 | `single` 槽的 `children` 声明是**独占**的：官方 entry 仍注册着该子槽声明，我们重复声明会抛错。故我们直接渲染 `model.name`；`dsh-client-ui-deepseek-model-label-1017` 的角标不再生效（无报错，只是不渲染） |
| 保留 reasoning-effort 的滑块外观 | 它只装饰「原生 entry」，single 槽遮蔽后原生 entry 不上屏 |

## 三、架构

**纯客户端插件，无 Host 业务逻辑。**
配置存 `localStorage`，设置页通过 `settings.section` 槽注册（客户端槽，无需 Host 半边）。

```
package.json          name=dsh-model-tabs, dsh.bundle.patch, dsh.client
cordis.patch.yml      挂载声明
lib/index.js          Host 半边：空插件（cordis.patch.yml 需要可解析的 main）
lib/client.js         构建产物（浏览器半边）
src/host/index.js     Host 半边源码
src/client/index.js   插件注册（slots.inject + 服务注入 + 挂载前退让）
src/client/ModelTabs.js  主组件：trigger + 菜单 + 两级 Tab + 列表 + effort
src/client/family.js  族分类纯逻辑
src/client/config.js  配置存取 + 校验 + 订阅
src/client/locale.js  zh / en 字典
tools/build.mjs       esbuild 打包（产出 __ModuleLoader__.load 包裹）
tools/check-family.mjs 族分类回归检查
```

### 3.1 槽位注册

```js
inject: ['slots', 'locale', 'sessions', 'modelDirectories']
ctx.slots.inject('conversation.input.model', () => ctx.slots.register(
  { name: 'conversation.input.model', locale: 'model-tabs', priority: -1000, inject: (sessionId) => {...} },
  ModelTabs,
))
```

**priority = -1000**：`single` 槽按 priority 升序取第一个渲染（越小越先）。官方 `0`，
`reasoning-effort` 的兜底分支是 `-100`，故取 `-1000` 稳压两者。

**挂载前退让**：`slots` / `modelDirectories` / `sessions` 任一缺失 → 直接 `return`，不注册，官方选择器照常出现。

### 3.2 组件结构

```
trigger  : [icon] modelName · effortLabel [chevron | spinner]
menu(portal, MenuSurface):
  pane=root   : 「模型」行 → drill model ；「推理等级」行 → drill effort
  pane=model  :
    [大目录] Provider Tab 行：全部 | <provider>...
    [大目录 且 已选具体 provider] 族 Tab 行：全部 | <family>...
    [choices > 4] 搜索框
    [status / error / failures]
    [列表]：小目录=按 provider 分组的平铺（吸顶组头）；大目录=当前 Tab 过滤后的平铺
  pane=effort : 档位列表（provider default + reasoning.efforts）
```

### 3.3 过滤链

```
groups
  → providerTab === null ? 全部 : 仅该 provider
  → familyTab   === null ? 全部 : 仅该族（仅当 providerTab 已选定具体 provider 时可用）
  → search 查询（保持官方 rankByName 口径：前缀优先 → 对齐分 → 目录序）
```

**族 Tab 只在选定具体 provider 时出现** —— 因为族是 provider 内部的子分类（符合「模型子 Tab」语义），
且避免跨 provider 族名合并成 20+ 个 Tab。

### 3.4 族识别算法（`family.js`）

```js
normalize(name):  取最后一个 '/' 之后 → 去掉 ':' 后缀 → 小写
classify(name):
  1. 在规则表里做「最长前缀命中」，命中即返回该 key
  2. 否则取前导字母串（/^[a-z]+/）作为 key
  3. 都没有 → 'other'
```

实测（本机 7 provider / 119 模型）：族碎片 **46**（纯首 token 方案为 53），
并修复了 `qwen` vs `qwen3`、`ling` vs `lingdt`、`hy4free`/`hy4std`/`hy3` 三类误拆。

### 3.5 配置（`config.js`）

```js
localStorage['dsh-model-tabs.config'] = {
  version: 1,
  thresholds: { totalModels: 20, perProvider: 30 },
  rules: [ { key, label, prefixes: [...] }, ... ]
}
```

- 读取失败 / 校验失败 → 静默回退内置默认值
- 规则按 `key` 合并：用户规则覆盖同 key 的内置规则，新增 key 追加
- 设置页提供 JSON 编辑 + 「填入模板」+ 恢复默认
- 持久化键用 provider/model **ID**，不用显示名（显示名会随本地化/目录变化）

### 3.6 与已装插件的关系

| 插件 | 影响 |
|---|---|
| `@ayanehana/dsh-reasoning-effort` | 其 `entry.component` 改写不再生效（原生 entry 不上屏）；不会报错。其设置页开关仍可正常使用 |
| `@txc2768651338/dsh-effort-slider` | DOM 级扫描找不到「推理等级」菜单行 → 静默无效果 |
| `dsh-client-ui-deepseek-model-label-1017` | 子槽无法复用，角标不渲染 |

## 四、验收标准

| # | 项 | 判定 |
|---|---|---|
| 1 | 大目录（本机 70 模型）出现两级 Tab | Provider Tab 有 7 项 + 全部；选 provider 后出现族 Tab |
| 2 | 小目录不出现 Tab | 人为把阈值调大，确认退回平铺 |
| 3 | Tab 过滤正确 | 选 `dsh-connect-trae/cn` → 33 模型；再选 `glm` → 7 模型 |
| 4 | 搜索与 Tab 叠加 | Tab 选中后输入 `5.3`，只在当前 Tab 内匹配 |
| 5 | 选中可提交 | 点模型行后 trigger 更新，且 reasoning effort 跟随该模型默认值 |
| 6 | effort 档位可用 | 推理等级面板列出该模型 advertised 的档位，选择后 trigger 显示新档位 |
| 7 | 键盘可用 | ↑↓ 移动、Enter 选中、Esc 逐级返回、Tab 聚焦搜索 |
| 8 | 服务缺失时退让 | 临时禁用 `modelDirectories` 依赖，官方选择器应照常出现 |
| 9 | 配置生效 | 设置页改规则 → 族 Tab 变化，刷新后保持 |
| 10 | 不误伤 `/model` | `/model` 弹窗外观与行为完全不变 |

## 五、风险点（交付时需用户决定）

| 风险 | 说明 |
|---|---|
| 官方升级漂移 | 我们复刻了原生约 640 行行为；官方 README 明写会有破坏性变更，且近一周在改浮层定位 |
| priority 约定脆弱 | 依赖 `single` 槽「小者优先」的未文档化约定；官方若改分配策略会失效 |
| 失去 1017 角标 | 子槽声明独占，无法复用 |
| 键盘行为非像素级一致 | 我们重写导航逻辑，与原生的边界情形（如 blur 时的焦点归还）可能不同 |
| 与竞品同质 | 187 个同类插件中 19 个已做 provider 分组、4 个已做族分组；差异化靠「族规则可配置」 |
